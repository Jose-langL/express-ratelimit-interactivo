# API de Videojuegos 

## Descripción

Este proyecto consiste en el desarrollo de una API REST para gestionar información relacionada con videojuegos, utilizando **Node.js** y **Express.js**.

Además, se implementa el middleware `express-rate-limit` para limitar la cantidad de solicitudes que un cliente puede realizar durante un período determinado, ayudando a prevenir el abuso de los endpoints y el envío excesivo de peticiones.

## Tecnologías utilizadas

- **Node.js:** entorno de ejecución de JavaScript.
- **Express.js:** framework para la creación de servidores y APIs REST.
- **express-rate-limit:** middleware para limitar la frecuencia de las solicitudes HTTP.
- **JavaScript:** lenguaje utilizado para desarrollar la API.
- **npm:** administrador de paquetes de Node.js.

## Características

- Creación de una API REST para videojuegos.
- Gestión de solicitudes HTTP mediante Express.
- Implementación de middleware para procesar las solicitudes.
- Limitación de peticiones utilizando `express-rate-limit`.
- Organización del código para facilitar su mantenimiento y ampliación.
